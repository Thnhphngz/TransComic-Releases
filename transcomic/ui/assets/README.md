# TransComic vectors

Original SVG artwork created for TransComic UI V2. No third party images or fonts embedded.

The logo combines two translation speech bubbles, a geometric T and a reply arrow.
Palette: bronze `#9B552C`, cream `#FFFCF9`, espresso `#30231D`, dark accent `#D88A4E`.

- `transcomic-main.svg`: master identity.
- `transcomic-light.svg`, `transcomic-dark.svg`: window/application theme variants.
- `transcomic-sidebar.svg`: sidebar variant.
- `transcomic-small.svg`: icon source explicitly registered for 16/20/24 px.
- `nav-*.svg`: original navigation outlines.

All paths remain editable. Qt renders the SVG at the requested resolution. Windows runtime sets the process AppUserModelID and Qt application/window icons; tray and exit dialogs inherit the icon. No EXE build is required for the Python application.
